# 万能悬浮启动球 (qidong.py)
> 基于 PySide6 实现的 Windows 桌面悬浮球命令启动器，点击悬浮小球弹出命令输入框，直接执行系统命令、调用 Ollama、记事本等程序，常驻托盘，置顶悬浮。

## ✨ 功能特性
- 🟡 **桌面悬浮小球**：置顶、可拖拽、半透明悬浮球，鼠标悬浮高亮
- ⌨️ **命令执行窗口**：点击悬浮球弹出无边框命令输入对话框
- 🖥️ **执行系统命令**：底层调用 cmd，实时回显命令输出日志
- 🦙 **Ollama 适配**：内置 Ollama 专项调用支持，直接在悬浮框执行 ollama 指令
- ⚙️ **配置持久化**：自动生成 `qidong_config.json`，自定义程序路径
- 🛑 **进程控制**：支持停止正在运行的长时间命令
- 📌 **系统托盘常驻**：后台运行，托盘菜单可显示悬浮球、退出程序
- 🎨 **无边框UI**：圆角窗口、透明背景，自带内置绘制图标，缺失图片也能正常运行
- 🔤 **编码兼容**：自动识别 Windows OEM 代码页，解决中文输出乱码问题

## 📦 环境依赖
- Python >=3.10
- PySide6

安装依赖：
```bash
pip install pyside6
```

## 🚀 快速运行

1. 安装依赖

```
pip install pyside6
```

2. 运行脚本

```
python qidong.py
```

3. 桌面出现悬浮小球，右下角系统托盘出现程序图标
4. **左键点击悬浮球**，弹出命令输入框，输入指令回车执行

## ⚙️ 配置文件 qidong_config.json

程序首次启动自动生成配置，可手动修改各个程序可执行路径。

```
{
  "notepad": {
    "path": "C:\\Windows\\notepad.exe"
  },
  "cmd": {
    "path": "C:\\Windows\\System32\\cmd.exe"
  }
}
```

> 
> Ollama 执行异常，请确认配置文件内 `ollama.exe` 路径为本机真实路径。

## 📝 操作说明

1. **拖拽悬浮球**：鼠标按住小球拖动到屏幕任意位置
2. **点击小球**：弹出无边框命令对话框
3. **执行命令**：输入指令回车 / 点击【执行】
4. **停止任务**：长时间运行程序，点击停止按钮终止进程
5. **关闭对话框**：点 × 关闭窗口，悬浮球继续后台运行
6. **彻底退出程序**：右下角托盘图标右键菜单选择【退出】

## ⚠️ 注意事项

1. **仅限 Windows**：代码调用 Windows ctypes API，Linux /macOS 不能直接运行
2. `R‑C.jpg` 是可选图片，文件不存在时，程序会自动绘制蓝色球体图标
3. 命令底层调用 cmd，遵循 Windows cmd 语法
4. 关闭对话框不等于退出程序，必须托盘菜单退出
5. 输出中文乱码：程序自动适配 OEM 编码，如仍乱码，检查系统本地编码设置

## 🛠️ 源码可调参数

在 `qidong.py` 顶部配置区：

```
BALL_SIZE = 64   # 修改悬浮球大小（像素）
```
