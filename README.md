# 万能悬浮启动球 (qidong.py)
> 基于 PySide6 实现的 Windows 桌面悬浮球命令启动器，点击悬浮小球弹出命令输入框，直接执行系统命令、调用 Ollama、记事本等程序，常驻托盘，置顶悬浮。

## ✨ 功能特性
- 🟡 **桌面悬浮小球**：置顶、可拖拽、半透明悬浮球，鼠标悬浮高亮
- ⌨️ **命令执行窗口**：点击悬浮球弹出无边框命令输入对话框
- 🖥️ **执行系统命令**：底层调用 cmd，实时回显命令输出日志
- ⚙️ **配置持久化**：自动生成 `qidong_config.json`，自定义程序路径
- 🛑 **进程控制**：支持停止正在运行的长时间命令
- 📌 **系统托盘常驻**：后台运行，托盘菜单可显示悬浮球、退出程序
- 🎨 **无边框UI**：圆角窗口、透明背景，自带内置绘制图标，缺失图片也能正常运行
- 🔤 **编码兼容**：自动识别 Windows OEM 代码页，解决中文输出乱码问题

- PySide6
